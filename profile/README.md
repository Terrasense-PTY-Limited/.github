### Field comms that keep working where the signal ends

**📱 TerraField app.** For rangers, anti-poaching units and conservation teams: messaging, a live team map, SOS, reports and tasks over a long-range **LoRa radio mesh** when there is no cell signal, synced to the cloud when it returns.

**🖥️ TerraSense Portal.** The control room for reserve managers: live map, reports, tasks, attendance and alerts, in the browser.
